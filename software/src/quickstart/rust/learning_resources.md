# Learning Resources
- [The Rust book](https://doc.rust-lang.org/stable/book/): This is the best primary resource for learning Rust in my opinion. It walks you through almost the entire language and has good tutorials.
- [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/): This covers a lot of the same material as the Rust book, but presents it as example code that is explained line by line.
- [Rustlings](https://rustlings.rust-lang.org/): This has some more approachable tutorials
- [Rust Cookbook](https://rust-lang-nursery.github.io/rust-cookbook/): This is a good supplementary resource that has examples for many common programming tasks.
